# JI-DAW Web

仓库同时提供单轨模式 `single.html` 和完整多轨模式 `complete.html`，首页可选择进入。完整模式源码位于 `complete-src/`，可独立从本仓库构建。

完整模式包含鼓轨、单鼓音量、SF2 鼓组、逐轨增益、声像、三段 EQ 和立体声房间混响。两套合成鼓的 snare 保留原始音色，仅提升输出增益 6 dB。音源菜单可直接加载 Touhou.sf2；为供静态站点加载，该音源以 `sound/Touhou.sf2.json` 清单和八个分块随仓库发布，浏览器会自动合并，音源数据保持一致。

`npm run build:complete` 构建完整模式；`npm run build` 会构建并同步两种模式的部署入口和资源。更新原始 Touhou 文件后，可执行 `node scripts/split-soundfont.mjs /path/to/Touhou.sf2` 重新生成分块。

纯浏览器运行的单轨纯律钢琴窗。保留任意分数音程、音程连接、十二音纯律吸附、富文本注释、内置采样与 SF2，并将工程、节拍和音色设置集中到钢琴窗。

## 使用

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

入口文件是仓库根目录可直接部署的 `index.html`，GitHub Pages 无需改目录。`index.source.html` 是开发入口；执行构建后，固定名称的脚本与样式会同步到根目录 `assets/`，完整构建也保留在 `dist/`。

首次打开会载入 `DEMO.jidaw` 并启动交互式教程；右上角 `?` 可随时重新打开教程。浏览器中的后续编辑会自动恢复，不会被 DEMO 覆盖。

播放跟随按钮提供关闭、光标锁定和小节翻页三种状态；小节翻页会在播放光标越过视口右侧最近的小节线时，将该小节起点对齐到钢琴窗左侧。

音符菜单可为单个音符设置独立颜色。调律设置保留固定调式，并支持从基音开始自由添加任意数量的纯律比例或任意 N-EDO 步数；界面会自动生成音名与音分偏差。调律表可导入、导出，也可保存为新工程默认值。

## 文件交换

- `.jidaw`：保存和打开完整单轨工程。
- `.jituning`：导入或导出独立调律表。
- 轨道码：压缩为可复制文本，包含音符、比例关系、注释及调律设置。
- MIDI：支持导入与导出；导出使用多通道 Pitch Bend 尽量保留纯律音高。
- MP3：在浏览器中按当前 BPM、音符时值、音色、音量和声像离线渲染为 192 kbps 立体声文件。
- SF2：浏览器会话内加载，工程重新打开后需再次选择原 SF2 文件。

MP3 编码使用 [`@breezystack/lamejs`](https://github.com/shijinyu/lamejs)（LGPL-3.0），仅在执行导出时动态载入。
