# JI-DAW Web

纯浏览器运行的单轨纯律钢琴窗。保留任意分数音程、音程连接、十二音纯律吸附、富文本注释、内置采样与 SF2，并将工程、节拍和音色设置集中到钢琴窗。

## 使用

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

入口文件是仓库根目录的 `index.html`。构建产物位于 `dist/`。

## 文件交换

- `.jidaw`：保存和打开完整单轨工程。
- 轨道码：压缩为可复制文本，包含音符、比例关系、注释及调律设置。
- MIDI：支持导入与导出；导出使用多通道 Pitch Bend 尽量保留纯律音高。
- SF2：浏览器会话内加载，工程重新打开后需再次选择原 SF2 文件。
